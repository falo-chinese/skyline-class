🚀 Skyline Class02 課程導覽與引導說明

Course Overview & Navigation Guide

歡迎來到 Skyline Class02 企業數位轉型實務課程。本階段課程的核心目標是引導主管與同仁建立「端到端一條龍工作流」與「AI 指揮官思維」。 我們將整體學習脈絡收斂為以下三大核心主題，請點選對應的主題按鈕或側邊欄連結開始探索：

🚀
Google 產品實戰

探索 Google 生態系的進階實務應用。從 Chrome 擴充功能開發、Google Apps Script (GAS) 雲端安全部署，到 ETL 資料清洗管道與 Google DeepMind 開發的 Antigravity 自主 Agent 協作，助您快速上手前沿的開發與自動化技術。

  • Manifest V3 Chrome 外掛開發與自動化填單
  • GAS Web App 安全防禦部署實踐
  • Python + CLI 自主 Agent 授權執行與 CoT 引導
進入實戰手冊 ➔

Agent 工具使用指南

地端 AI PM 人機架構的實操指南。本單元詳細記錄了如何配合地端 AIDE/Codex 指令特工進行「一條龍」招標合規比對、財務毛利試算、SLA 響應落差分析與建議書草稿自動組裝。

  • FinOps Token 費用監控與 Google Sheet 自動寫入
  • 行政與人工審查欄位精簡/完整雙模式切換
  • 提示詞黃金雙軌與智慧投標控制塔 POC 動態連動
