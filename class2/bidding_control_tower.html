🤖 展會投標 AIDE 控制塔 (Bidding Control Tower POC)

展覽總包工程標案之雙軌人機協調控制台 (台南玩具展案例)

本控制塔展示了在「台南玩具總包標案 (450萬元)」中，AI 如何協助高階主管與基層同仁進行安全的雙軌對帳、SLA 響應、爬蟲分析與 3D 展位圖自動組裝。提供手動與 API 雙模加速操作。

💡
系統分工說明：指南 (Reference) vs 控制塔 (Cockpit)

• 📖 Agent 工具使用指南：屬於靜態說明指引。記錄了地端開發者在專屬主機上進行檔案掃描、RFP 對帳及草稿合併時的「具體 Prompts 與 CLI 指令」，做為知識庫參考手冊。
• 🖥️ 智慧投標控制塔 (POC)：即本網頁，屬於動態操作控制台。它將指南中的 5 大靜態指令，整合為「一條龍」人機協同流程。您可以在下方點選任一節點，即可展開該步驟的「地端輸入檔案、編譯 Prompts、與對帳數據輸出」所有細節！
