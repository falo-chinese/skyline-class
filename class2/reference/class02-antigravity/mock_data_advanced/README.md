# 🚀 星河 Class 02 實作資料集 (進階實戰版 - Advanced Sandbox)

本資料集專門為 **星河 Class 02 — 企業知識資產化與 AI 應用實務** 的「進階實戰標案攻防戰」所設計。資料夾經完全去識別化，採用假名專案（星河科技、鼎盛實業、浩宇專案），無任何真實隱私個資。

---

## 🎭 實作故事背景 (The Scenario)
你擔任 **星河科技** 的投標專案經理（PM）。公司正準備投標國家檔案數位發展委員會的 **「國家智慧文件政務工程導入標案」**（預算 500 萬）。
投標截止只剩 **3 天**，你必須帶領團隊進行快速、嚴密的合規文件組裝。

然而，在本次實戰中，你面臨了真實專案中高頻發生的**「決策分析」**與**「管理雷區」**挑戰：
1. **多個歷史專案樣本篩選**：公司手上有很多過往實績（ERP、CRM、Portal等），你需要讓 AI 幫你比對 RFP 的硬性條件，篩選出**唯一合法、合規且風險最低的「最佳投標實績」**。
2. **核心人員資格死穴**：RFP 規定專案經理（PM）必須持有有效之 PMP 證照。但平時沒有人去複核證照效期，投標前一秒才發現 PM 志明的 PMP 證照已於去年底過期！
3. **技術回應差距 (SLA)**：公司標準的 SLA 維護響應是 **4 小時**，但外部 RFP 規定緊急事件必須 **2 小時內** 到達現場，你必須進行 **「小幅增強 (Enhancement)」** 來對帳合規。

---

## 🗂️ 資料夾導覽
* `01_rfp/`：包含進階招標書、人員投標附錄與納稅門檻。
* `02_internal_knowledge_assets/`：包含標準簡介、3個歷史專案元件、SLA 元件、以及 PM 志明與架構師國華的個人履歷。
* `03_missing_items/`：多重風險與缺件登錄表。
* `04_student_templates/`：供現場練習的進階空白對照工作表。
* `05_answer_keys/`：包含「多案例篩選推薦」、「證照失效避險」及「SLA 小幅增強」的標準答案庫。
* `06_antigravity_prompts/`：AIDE 6 階段高階 Agent 指令集，展示決策分析與自動編譯。
* `07_expected_outputs/`：一鍵編譯出的第二章方法論草稿（SLA已自動優化至2小時）及 JSON 中控指標。
