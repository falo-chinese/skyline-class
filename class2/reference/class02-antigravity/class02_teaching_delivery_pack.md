> 
> **工具是雙手，管理是天眼。讓 AI 載入基本母版，自動核對 RFP，產出雙軌 Gap Checklist，由人參考與最終確認，這才是最安全的現代標案生產線！**」

### 📥 1. 核心知識工程：一般 Excel 檔案 (.xlsx) 導入與 PWA 雲地同步戰略

在 Class 02 中，我們教導學員處理傳統 Excel 的匯入限制。結合 **Skyline Prompt Hub PWA** 的精神，我們可以將 Excel 導入與 Prompt 資產管理進行整合：

#### 🔄 雲地同步戰略：本地 PWA 殼 + 雲端 GAS 派發
1. **地端 PWA 獨立視窗應用（地端安全）**：學員可透過 [Skyline Prompt Hub PWA](../skyline_prompt_hub/index.html) 在本地斷網下直接拖放 `.xlsx` 或 `.json` 插卡檔案。SheetJS 引擎在瀏覽器內核沙盒中執行解析，資料不落地、不耗 API 額度、100% 保密。
2. **雲端 Apps Script API（雲端即時派發）**：管理者可將最新 Prompt 與經驗元件維護在 Google Sheets 中，一鍵部署為 Apps Script Web App。PWA 端只要填入 GAS URL，即可實時拉取全公司最新的分類與指令卡片，兼具保密性與同步便利性。

#### ⚠️ 核心限制與痛點
在 NotebookLM 的「新增來源」中，**原生並不支援標準的 Excel (.xlsx) 二進位檔案格式**（支援的檔案類型：`pdf, txt, md, docx, csv, pptx, epub...`）。若直接上傳 `.xlsx` 會產生格式不支援錯誤。為了將傳統扁平的 Excel 組織記憶灌入 AI 大腦，PM 必須掌握以下兩種各有優勢的導入重構路徑：

*   **🟢 路徑一：雲端試算表直連法 (Google Sheets Live Link)**
    *   **步驟**：將 `.xlsx` 檔案上傳至 Google Drive ➔ 以 Google 試算表開啟 ➔ 點選「檔案」➔「儲存為 Google 試算表」 ➔ 前往 NotebookLM 點選「Google 雲端硬碟」直接導入該 Google Sheet。
    *   **🔥 最大優勢 (PROS)**：**手動更新與動態自癒**。這是最推薦的工業級做法。當前線 PM 在雲端試算表中隨時修改、更正或追加新的專案踩坑行數時，**無須重新轉檔或二次上傳！** 只需在 NotebookLM 的該檔案來源旁點擊 `🔄 重新整理來源 (Refresh Source)`，大腦便會秒級快照吸收最新內容，確保企業知識庫的「動態演進」。
*   **🟣 路徑二：AI 轉換 .csv 直接上傳法 (AI CSV Conversion)**
    *   **步驟**：將原始 `.xlsx` 表格或截圖直接投餵給 AI 特助 ➔ 發送指令 `「請幫我將這份 Excel 專案經驗庫，格式化清洗並轉譯輸出為標準的 .csv 檔案，以供 NotebookLM 讀取。」` ➔ 下載 AI 產出的 `.csv` ➔ 在 NotebookLM 中點選「上傳檔案」直接上傳導入。
    *   **🔥 最大優勢 (PROS)**：**高隱私與免授權**。由於 NotebookLM 原生支援 `.csv` 格式，此方法免去了雲端硬碟 of 權限授權，非常適合對外高度保密、敏感資料不落地、或只想進行單次靜態快照特訓的專案情境。轉換完全由 AI 自動處理，SME 行政同仁 0 學習成本。

#### 🗣️ 講師授課口白 (Verbatim)
> 「各位主管請看大螢幕，NotebookLM 支援很多檔案，但就是不支援我們每天都在用的 `.xlsx`。為什麼？因為傳統 Excel 是高密度的二進位二維表格，AI 沒辦法直讀它的脈絡。所以我們今天教大家兩種重構心法：如果你要長期管理，請用 Google Sheet 雲端直連，因為它有 **『一鍵更新』** 的動態自癒能力；如果你是單次分析、有保密限制，直接丟給 AI 特助轉成 `.csv` 丟進來。**方法沒有高下，能解決你當下業務痛點的，就是最好的方法！**」

### 📡 2. 現場演示微型 Prompt 與授課重點

*   **📡 微型 Prompt 1：關鍵字雷達 (Keyword Alert)**
    *   **指令**：`請以專業活動 PM 視角，掃描這份專案經驗庫的所有痛點，找出最常在「舞台現場」與「走線安全」上重複發生的安全風險（如電線凸起、音響太大聲等），並列出其發生的 Row 編號與簡述。`
    *   **🗣️ 講師授課重點**：教導學員利用 RAG 在幾秒鐘內抓出高頻安全雷區，避免肉眼翻閱 36 筆的延遲。
*   **🔍 微型 Prompt 2：避雷針提煉 (Golden Finder)**
    *   **指令**：`請從 Row 7（電線凸起絆倒記者會長官母女）與 Row 6（承辦休假審核 Delay 印刷趕工）中，分別提取其「痛點描述」、「當下應變」與「最核心的避雷防禦建議」，並用條列式整理。`
    *   **🗣️ 講師授課重點**：針對特定歷史慘痛教訓（Row 7 cables safety, Row 6 approval timeline）進行深度提煉，展示 AI 如何將「踩坑經驗」自動收斂成「標準行動防線」。
*   **💡 微型 Prompt 3：行動方案組裝 (Action Assembler)**
    *   **指令**：`請基於該經驗庫的教訓，為我們即將舉辦的下一次大型戶外寵物市集，撰寫一份 5 條核心安全巡檢 Checklist，重點預防長官跌倒與攤商混亂。`
    *   **🗣️ 講師授課重點**：展示如何從過去的「組織記憶」無縫生成未來的「開案 Checklist」，讓歷史經驗具備主動防禦力。
*   **🏷️ 微型 Prompt 4：一秒分類與標籤 (1-Second Labeling)**
    *   **指令**：`請閱讀以下這筆新 PM 現場問題：「活動最後一天，寵物市集店家抱怨撤場動線狹窄、大貨車倒車差點撞到民眾狗狗，工讀生不知道該找誰指揮撤場。」請比對經驗庫的分類體系，為其自動分類並打上 3 個核心標籤（Tags）。`
    *   **🗣️ 講師授課重點**：展示 RAG 自動對齊組織分類結構，做知識標籤歸檔的無感工程。

### 🧱 3. 知識拆解與積木化：將 Excel Rows 重構為標準 SOP 物理元件

講師現場演示：平鋪的 Excel 表格行不是最終防線。我們必須請 Antigravity Agent 自動將這些散落的行，重構為具有 **SOP 標準化** 與 **自動觸發防線** 的 Markdown 知識積木元件：

*   **`comp-07_onsite_wire_safety.md` (現場電線鋪設與走線安全 SOP)**
    *   **🏷️ Tags**：民眾跌倒, 電線固定, 三角錐, 現場安全, 音響廠商
    *   **🔴 歷史痛點**：舞台區連結到長官報到處電線凸起未固定，致民眾絆倒受傷。
    *   **🛡️ 標準防線 SOP**：
        1. 走線區域必須規劃明顯防護標示，嚴禁裸露電線。
        2. 嚴格要求音響硬體廠商在活動前以黑黃大力膠完全黏貼固定地面電線，並在交叉路口配置橡膠護線板。
        3. PM 必須於活動開場前 1 小時逐一走線巡檢拍照存檔。
    *   **⚙️ 觸發規則**：當 RFP 包含「舞台搭建」或「硬體施工」時，強行將此 SOP 鋪裝入投標書或專案合規矩陣。
*   **`comp-06_gov_approval_timeline.md` (政府機關設計審核與安全製程控管)**
    *   **🏷️ Tags**：審核Delay, 進度落後, 修改Logo, 印刷時間
    *   **🔴 歷史痛點**：承辦休假審核延誤，活動前兩天還在修改攤名標誌，前一天印刷品才送達。
    *   **🛡️ 標準防線 SOP**：
        1. 專案啟動時，PM 必須與業主科室約定明確的「設計審核通過截止時間」與「最後修改截止時間」。
        2. 印刷發包品必須在出發前預留至少 3 天的安全製程與物理物流運輸時間。
        3. 若承辦休假，開案時必須在會議記錄中指定指定的第二審核代理人。
    *   **⚙️ 觸發規則**：當合約對象為「政府機關/業務單位」，且時程在「準備期/籌備期」時，自動啟用本防禦元件。

### 🚀 4. 全景整合生態：既有資產增強（Path A）與新增防禦類別（Path B）

雙軌自癒系統的終極展現：經驗庫表格絕非孤立的存檔，AI 特助 Antigravity 會自動沿著兩條演進路徑，重塑公司的標準防線，讓整個企業大腦具有強大的自我免疫能力！

*   **🟢 Path A: 既有資產增強 (Enriching Standard Assets)**
    *   **機制**：屬於重複發生的標準安全風險（如走線絆倒）。
    *   **AI 自助作業**：Antigravity 在背景會自動將 `comp-07_onsite_wire_safety.md` 中的 SOP 電線黏貼規則，**寫入並合併至星河科技標準專案管理方法論 `skyline_pm_methodology.md` 的第四章「現場安全控管」中**。未來投標書調用此方法論時，將自動具備此電線安全防護條款，投標書「越做專案越強」！
*   **🟣 Path B: 新增防禦類別 (Creating New Defense Perimeter)**
    *   **機制**：暴露了前所未有的新型風險（如 Row 34 攤商提早撤場亂象，或 Row 24 啟動道具珍珠板尺寸反覆修改）。
    *   **AI 自助作業**：大腦發現這不屬於既有的公司簡介或 PMP 等標準資產。Antigravity 會**自動在專案目錄下創建一個全新的文件夾與文件：`case4_stall_management/stall_exit_rules.md`**！並寫入專屬的攤商管理切結與工讀生超時調派規則，自動拓寬公司的防禦疆域！
