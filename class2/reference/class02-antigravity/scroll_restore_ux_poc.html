⚙️ 下一代 UX 心法解析：滾動回溯與視線聚焦技術

1. 痛點分析：傳統跳轉的「滾動地獄 (Scroll Trap)」

在單頁應用（SPA）或大型標籤頁面中，使用者在 Tab A 點擊跳轉到 Tab B 閱讀細節。然而，在 Tab B 閱讀完畢點擊「返回」後，系統通常只會做單純的標籤切換，滾動條會停留在最頂部，迫使使用者必須「重新用肉眼往下滾動尋找」剛才的閱讀位置。這種體驗被稱為「滾動重力地獄」，會極大程度干擾教學或展示的流暢度。

2. 核心觀念：滾動記憶法 (Scroll Memory Strategy)

我們的解決方案只用簡單的純 JavaScript 便能實現，完全不依賴任何外部前端框架（如 React/Vue）。

概念公式： 記住起點 ➔ 切換分頁 ➔ 平滑滾回起點 ➔ 呼吸高亮引導

3. 核心 JavaScript 代碼（一目了然）

您可以將此處代碼直接複製到您自己的專案中使用：

// 1. 定義全局變數，用來記憶 Y 軸高度
let lastSyllabusScrollY = 0;

// 2. 跳轉函數：記錄位置 ➔ 切換 Tab ➔ 滾動到細項
function syllabusJump(index) {
    // 💡 核心：將當前視窗滾動條的高度，記在變數裡
    lastSyllabusScrollY = window.scrollY; 

    // 模擬切換標籤頁 (切換到細項頁)
    switchTab('tab-detail');

    // 滾動到特定細項卡片
    setTimeout(() => {
        const detailElement = document.getElementById('detail-part-' + index);
        if (detailElement) {
            detailElement.scrollIntoView({ behavior: 'smooth', block: 'center' });
        }
    }, 200);
}

// 3. 返回函數：切回大綱 Tab ➔ 平滑滾回原位置 ➔ 呼吸燈聚焦
function returnJump(cardId) {
    // 切換回大綱頁
    switchTab('tab-syllabus');

    setTimeout(() => {
        // 💡 核心：自動平滑滾動回剛才記憶的 Y 軸高度
        window.scrollTo({
            top: lastSyllabusScrollY,
            behavior: 'smooth'
        });

        // 視線聚焦：為剛剛點選的卡片加上 glow 呼吸動畫
        const card = document.getElementById(cardId);
        if (card) {
            card.classList.add('glow-active');
            // 動畫結束後移除 class，以利下次點擊
            setTimeout(() => {
                card.classList.remove('glow-active');
            }, 2000);
        }
    }, 150);
}
