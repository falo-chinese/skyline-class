🧩 資訊安全維護政策規範 (Information Security Policy)


檔案用途：星河科技標準資安切結條款，用於組裝滿足 REQ-02 切結書。

教學重點：對齊 RFP 「資料不落地」與「每季定期風險稽核」的兩大死命令。



一、資訊安全承諾

星河科技履約環境完全符合國家最新資安規範。


二、核心資安條款

  1. 資料傳輸不落地：星河科技承諾，本專案所有智慧文件之處理與傳輸，均採用 SSL 256-bit 高強度加密，資料處理於內存中即時完成，保證 「資料不落地」，不留存於任何第三方伺服器。
  2. 每季定期風險稽核：星河科技得標後，將全力配合業主，於合約履行期間，每季配合進行一次定期資訊安全風險稽核與漏洞掃描，並主動向中控台同步稽核報告。
