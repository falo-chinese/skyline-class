# 🌌 星河 Class 02 企業知識資產化實作資料集 (Mock Dataset)

本資料集專門為 **星河 Class 02 — 企業知識資產化與 AI 應用實務** 的現場實作所設計。資料集完全去識別化，使用模擬的企業與專案資訊（如「星河科技」、「鼎盛 ERP 專案」、「浩宇專案」），且不包含任何真實的客戶隱私、個資、地址與統一編號。

---

## 🛠️ 實作核心學習流程
本資料集支援學員在課堂上親自完成以下文件工程閉環：
1. **閱讀模擬 RFP** (在 `01_rfp/`) ➔ 提取外部死命令。
2. **對照知識積木** (在 `02_internal_knowledge_assets/`) ➔ 盤點企業可用無形資產。
3. **填寫練習表** (在 `04_student_templates/` 練習，對照 `05_answer_keys/` 答案)。
4. **發現缺件與風險** (在 `03_missing_items/` 與避險卡對照) ➔ 攔截廢標危機。
5. **運行 Antigravity 提示** (在 `06_antigravity_prompts/`) ➔ 指揮 Agent 進行長文件一鍵組裝與 Diff。
6. **審查與同步中控** (在 `07_expected_outputs/`) ➔ 產出 100% 合規標書草稿並回推 Skyline PM。

---

## 🗂️ 資料夾結構導覽
* `01_rfp/`：包含精簡版與完整版模擬招標規範書。
* `02_internal_knowledge_assets/`：包含星河科技 6 大標準知識元件積木。
* `03_missing_items/`：記錄真實專案常發生的實體缺件與避險邏輯。
* `04_student_templates/`：提供給學員現場練習的空白表單。
* `05_answer_keys/`：標準答案庫，供對答案或快速對帳使用。
* `06_antigravity_prompts/`：AIDE 文件工程的 5 階段 Agent 指令集。
* `07_expected_outputs/`：預期產出的投標書草稿、總經理審查卡與中控欄位。
